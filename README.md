### 📂 Proyek Unggulan

#### 🚀 [Smart Radiation Portal Monitoring System](https://github.com/Sanjehaqi/-Smart-Radiation-Portal-Monitoring-System)
Sistem gerbang pemantauan radiasi otomatis berskala industri dengan 3 Node ESP32 terdistribusi berkomunikasi via ESP-NOW nirkabel.
* **Slave 1 (HMI)**: GUI Dashboard premium menggunakan **LVGL** pada TFT LCD 5 Inci.
* **Slave 2 (Sensor)**: Mengakuisisi data dari Geiger-Müller Kit, MQ-135, DHT11, dan BMP280.
* **Slave 3 (Aktuator)**: Mengontrol motor stepper **NEMA 23** untuk pemindaian linear dan H-bridge *linear actuator* gerbang.
